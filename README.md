### Проект приложения для отправки рассылок пользователям

- Реализованы модели получателя, сообщения, рассылки, попытки рассылки и пользователя.
- Реализованы права доступа для пользователей и модераторов.
- Скрыты лишние кнопки для пользователей, не являющиеся владельцами сообщений, рассылок и получателей.
- Реализованы кастомные команды для создания админа (`python manage.py create_superuser`), группы менеджеров (`python manage.py create_manager`) и отправки рассылки через консоль (`python manage.py send_letter`)
- Реализована регистрация пользователей с подтверждением электронной почты и возможностью восстановить пароль.
- Реализовано серверное и клиентское кеширование для повышения производительности. (установлено 10 секунд для удобной проверки работы кэша)
